# Rashika-C1
library management system 
## Introduction
Library Management System is a database
project used to manage library activities.

## Features
- Add Books
- View Books
- Search Books
- Manage Students
- Issue Books
- Return Books
- Manage Library Staff

## Technologies Used
- MySQL
- SQL
- Database Management System

## Database Tables
1. Members
2. Books
3. Loans
4. Staff

## How to Run
1. Open MySQL.
2. Run library_management.sql.
3. Run sample_data.sql.
4. View the database tables.
5. Execute SELECT queries.

## Conclusion
This project helps manage library records
easily and efficiently.
